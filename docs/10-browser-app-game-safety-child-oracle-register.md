# Browser assertions: page effects, native transport and notice limits

The browser tests inspect selected DOM state, canvas samples, cache behavior and injected API responses in a running page. Those checks are stronger than a stand-in action log for their named page effects, but they do not establish physical input delivery, complete semantic state or the required fault notice merely because a helper or console assertion passes. This child register keeps the measured surface and independent expected relation separate.

Candidate source reconciliation for independent review. No execution, finding promotion, correction, permanent-test change, property certification or Phase 4 exit.

The configuration declares three projects: mobile-size WebKit, mobile-size Chromium and desktop Chromium. Project labels are not authentication of a physical device, OS or shipped Safari. Chromium-only install and Tab-focus rows explicitly skip WebKit. Chromium coverage captures only entries whose URL pathname ends in `/script.js`; coverage collection is not an independent oracle or a certificate for imported game modules.

Shared helper limits:

- `savedGame` constructs a real GameManager with memory storage, a scheduler returning handle 0 and a factory repeatedly copying an `allPieces`-derived selected kind. It starts New Game, directly injects board/position/rotation/score, then uses production Pause/serialization. This is a custom-factory/injected-state fixture, not independently established ordinary seven-bag history or B16-good content. `rowsExcept` independently enumerates a 10-column list, but its use still needs board/kind/geometry/admission grounding.
- `continueSavedGame` seeds literal storage keys once per session, delivers KeyC and waits for the Pause button's `aria-label` to say Resume. That is a page-label observation, not a direct engine mode/resource or full restored-state observation.
- `boardCells` samples the center of each of 20 by 10 canvas cells. Alpha greater than 200 selects a sampled color; ghost outlines are expected not to occupy the centers. `filledCount` counts these samples. These are actual canvas readback calls, not independent reconstruction of all engine fields or full visual inspection. Missed/off-center/outline content, occlusion, ghost geometry and visual readability require separate evidence. `canvasHasDrawing` scans for any alpha greater than 200, not exact preview identity/shape.
- `PieceColors`, `BOARD_COLOR` and factory shapes come from production. Literal counts/coordinates and requirements can supply independent expected relations, but production color membership, shape generation, serializer or self-comparison cannot certify its own semantics.
- `trackErrors` observes pageerror messages and console messages of type error. An empty list is an absence of those observed signals, not proof of every invariant or of the separate player-notice criterion. The drawing row captures console errors only.
- `fakeWakeLock` replaces the API with controlled EventTarget sentinels and request/grant/release counters. Those exact sequences test project policy, not physical screen sleep, battery policy or native API delivery. Resolution, visibility and dialog-cancel injections likewise remain synthetic at their stated cuts.
- Playwright keyboard and mouse/locator actions run through the browser automation surface; they are not direct GameManager calls, but no physical keyboard/controller, touch or operating-system transport is measured here. The controller dialog row replaces getGamepads with a standard-index object and waits two RAFs between presses/releases. It observes actual DOM activation downstream, unlike the unit controller press stub; the provider and press history remain synthetic.

D27 W1 trusts successful specified browser API semantics, not the project's arguments, sequencing, mappings or handling. W3 says that trust establishes no requirement. D22 T1 requires both an on-screen internal-error stop message and a separate test-observable signal. D23 U2 requires a small noninterrupting drawing/controller notice plus a separate signal. A console count, redraw count, label or safe-looking endpoint alone is insufficient for either report criterion. D23 U4 includes held-repeat, gravity and lock-delay checkpoints, not just the outer drawing/polling loops.

## Remaining child closeout

The source assertions are not current run receipts. Each child still needs the exact existing execution receipt and criterion/fixture correspondence where it is used as audit evidence. Assertion literals have structural separation from a production predicate; original author independence and O8 model independence are separate, unestablished questions here.

Actual page DOM activation in BG-05/06 and delivered defaultPrevented in BG-09 must not be flattened into unit-stub dispatch, but synthetic pad/focus/visibility/API premises must not be upgraded to physical delivery. Conversely a page label/pixel count is not an authoritative-state certificate. Establish the sampled-pixel-to-semantic-cell relation, canonical kind/geometry mapping, full accepted/prior-good payload denotation and applicable finite event/resource bounds independently before making broader claims.

The current controller register and AUDIT record carry the scoped conditional INP-4 missing-selected-Cancel-response disposition. The page blur expectation in BG-06 and omission of subsequent A in BG-10 are not an independent compliant answer for that finding's logical-choice premise. Cache title/root-entry successes do not refute separate foreign-creator, pin-order, clock-jump or failed-download/rebinding records. DSP-4 native quick-tap/recovery limits remain separate from computed CSS and a dispatched gesture.

Neither SAF-3's T1 player stop message nor SAF-5's U2 player notice is certified by these rows. Fault signal/report success, actual visible notice, noninterruption, whole engine safe stop and timer scope must remain separate obligations. No visual notice/pixel screenshot was inspected or new browser run made in this source-reading task. No game/test/CI/settings or existing register was changed. Browser/app/input/safety parent properties are not newly established; Phase 4 remains OPEN.
