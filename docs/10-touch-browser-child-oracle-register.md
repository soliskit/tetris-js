# Touch browser assertions: gesture answers and the writer-route boundary

The touch browser tests check selected color-cell geometry, drag positions, hold-preview drawing and zoom-policy adapters. Their answers do not, by themselves, establish every gesture's semantic state, native delivery or physical zoom recovery. This child register keeps each asserted result separate from those wider claims and joins the selected gestures to W30-W33.

Candidate source reconciliation for independent review. No execution, finding promotion, correction, permanent-test change, property certification or Phase 4 exit.

`savedGame` builds through real GameManager, allPieces-derived repeated-kind factory, fake scheduler, direct board/position/orientation/score injection and production Pause serialization. Continue then KeyP enters play. This is not independently B16-good content, ordinary seven-bag history or complete checkpoint admission. Individual geometric premises can be checked from the fixed table and declared coordinates without certifying that history. Imported PieceColors and BOARD_COLOR bind production palette identities, not an independently authored color contract.

`cellsOf` samples opaque cell centers from the canvas and selects exact imported color values; ghost outlines are intended not to count. `shapeOf` subtracts minimum row/column and sorts relative coordinates, so it discards translation. A changed normalized shape is not an exact next-orientation answer. `canvasHasDrawing` accepts any opaque pixel, not specifically a correctly held kind. Browser pixels read by these tests are the proposed measurement method; this register inspects no newly rendered pixels.

`boardTouch` derives CSS cell width from the board bounding box. Chromium uses CDP Input.dispatchTouchEvent; other browsers use mouse move/down/up. Down and move coordinates are explicit, with moveBy partitioning into declared steps. The end helper supplies no distinct endpoint coordinate. Neither adapter models physical finger precision, all pointer delivery schedules, capture refusal or cancelled/retained events. CDP injection is not physical hardware; WebKit's mouse substitution is not a native finger-drag result. Test coverage collection observes script execution, not oracle independence or state correctness.

## Governing criterion and W30-W33 join

INP-5 supplies tap, half-cell horizontal onset, per-cell moves/drops, wall alignment, original-piece restriction and hold. D33 C2 commits rotation at touch end only if the endpoint is within 10px; cancel commits none. D34 E1 also excludes any gesture that went beyond 10px, even if it returns. Already committed moves/drops stay committed. These semantic answers are separate from selected adapters and saved-fixture admission. The inclusive exactly-10px reading remains a candidate in `1-phase-4-touch-boundary-disposition-cuts.md`; this register does not settle it.

D32 operations 7/8/9 assign item 14 to touch begin/update/end, with move/soft-drop/rotation effects supplied by the gameplay operations. B12 describes semantic gesture state; Z1 preserves all unassigned authoritative items. B6/B12 give ordinary game-over touch/current-piece values no semantic meaning and do not require clearing retained concrete fields. Concrete reset or identity equality must therefore be connected to a semantic projection, not treated as the criterion itself.
