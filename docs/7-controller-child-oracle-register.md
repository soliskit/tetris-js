The 47 named controller tests contain useful independent literal dispatch and fake-time answers. A manual tick advances in at-most 10 ms pieces. The manager normally only logs requests; it does not change mode/confirmation when handleAction is called. questionButtons.move/press normally only append strings. One View+A row separately uses real GameManager with createFakeScheduler, createMemoryStorage and fixedFactory(cyan). Expected action tokens imported from production are identities; independent INP-1 through INP-4 and STA-1 meaning supplies the expected mapping. No actual browser/default event or physical controller delivery is authenticated by those fixtures.

D34 E2/E3 suppress controls held across Resume until released/repressed; normal-playing newest-direction expectations cannot override that exception. Selected paused-resource/checkpoint, alias-token and held-softdrop findings retain their own records. SAF-5/notice criteria are not settled by a console-call assertion.
