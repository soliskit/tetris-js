# Settled modal Resume is not a physical click route

A physical click on the page's Resume button cannot reach its handler once the modal dialog is open: the containing document outside that dialog is inert. This grounds one admission cut. It does not reject the programmatic Resume source discrepancy or the pre-native-open window.

Proposed bounded admission disposition for independent review. No new browser experiment, universal native proof, operation rule or finding promotion.

## Evidence and contract

Current script59fcb334 calls showModal in syncControls when pending becomes true. Resume is outside the dialog; its listener calls togglePause. Source HTML placement and script wiring are unchanged on main230cd4b.

https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal states that all elements in the containing document except dialog/descendants become inert. https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert states inert elements cannot be focused or clicked by the user and do not fire click events when clicked. This supports the ordinary successful-modal physical-click exclusion. It does not establish programmatic .click suppression, native API availability/failure or all assistive technologies.

## Legal-sequence comparison

A Cancel/no-answer operation commits paused/pendingfalse. A subsequent Resume operation may commit playing. Those two operations are legal as a two-event history; that existence does not explain a single physical event that STA1 requires to keep paused. For a declared programmatic/API event, admissibility and granularity must be fixed before using such a composite. The adopted texts do not make every implementation call one operation, so neither a one-call violation nor unrestricted multi-operation rescue is inferred.

This narrows the pending-Resume candidate's physical settled route and isolates the real remaining source/admission classes. It is not an owner question. No new normative reading is selected, no no-choice default adopted, no originalV85 hash recovery claimed.
