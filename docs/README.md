# Documentation

This folder is the project's public record of technical decisions and evidence.

Three files give the whole project. The rest is drill-down.

**What** - [the readme](../README.md) describes the game. The table below indexes technical records. [The Tetris Project](https://github.com/users/soliskit/projects/6) owns work order and current status.

**Why** - the [requirements](requirements.md): the current contract - rules, statuses and evidence limits; earlier detail remains in git history.

**How** - one folder per piece of work, named for the work, holding its records and evidence.

**Plans** - [Faster CI](https://github.com/soliskit/tetris-js/milestone/2) and [Modern Gameplay](https://github.com/soliskit/tetris-js/milestone/3) hold the complete public charters. Planning does not activate implementation.

**Sources** - [sources/](sources/) holds reference material the records cite.
